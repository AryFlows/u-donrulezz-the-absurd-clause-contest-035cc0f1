One absurd clause hidden deep inside a terms-of-service agreement, for the
make.fun competition **The Absurd Clause Contest**.

## The clause

> Section 14.2: by using this service, you agree to lend your dreams to the company on alternate Tuesdays, returnable only upon written request in triplicate.

(156 characters, one sentence.)

The joke is the register doing the work: it reads like real boilerplate
until "lend your dreams" lands, and the triplicate-request punchline keeps
it deadpan to the last word.

## Run

```sh
python3 main.py
```

Writes the clause to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). Python 3 standard library only, no network, no secrets.
